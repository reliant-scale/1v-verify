# License boundary for the standalone verifier candidate

The Founder approved **Apache-2.0 for the standalone `1v-verify` distribution only** on 2026-10-22. The complete license text is in this directory's `LICENSE` file. This staging directory is intended to become a separate verifier repository; it is not a license declaration for its parent estate.

The licensed work at release will be the files RST explicitly places in the separately packaged verifier repository after ownership, dependency and CC security review. Apache-2.0 gives recipients the rights stated in that license to the licensed work, including its applicable patent grant. This scope note does not narrow those rights once a file is distributed under Apache-2.0.

The 1V issuing runtime, ROG/SIGIL signing systems and keys, Atlas and 1Ve private implementation, customer material, and RST names and marks are **outside this verifier distribution**. Copying any code or documentation from those systems into this repository requires a separate rights and dependency review. Existing licenses on previously published material remain in force.

This is a staged license decision. The repository is still unimplemented and unpublished. The release manifest, dependency inventory, copyright notices and final packaged contents must pass CC's V-3 gate before Founder publication.
